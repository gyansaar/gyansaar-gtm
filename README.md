# gyansaar-gtm

Private repository for GyanSaar's go-to-market planning: target lists, positioning, sales motion, pricing thinking, pilot terms.

**Not code.** No CI, no builds, no engineering deliverables. If a change here would affect the product, it needs to happen in the PRD (`gyansaar-engine/PRD-GyanSaar.md`) first.

## Contents

- [`GTM-Plan.md`](./GTM-Plan.md) — living GTM plan, versioned in-file. See its change log for history.

## Convention

- Branch per change, PR to `main`, review before merge — same as every other gyansaar repo.
- Every material change bumps the version in the plan's change log.
- Do not commit lists of individual buyer contacts (names + phone numbers) unless obtained with the person's consent. Institution names and public contact routes are fine.
